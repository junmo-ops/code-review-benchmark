# SWE-PRBench 内部大模型评分

2026-10-01 起新批次使用 `--suite swe_prbench_llm`。目标是固定条件比较内部工具、模型，不追求官方榜单复现。

- 复用原始 SWE 数据、人工标注筛选、上游裁判提示词、严格响应校验与调用审计。
- 只统计裁判确认的配对；按原答卷顺序一对一去重。重复命中参考不重复加分。
- 精确率=一对一命中数/生成意见数；召回率=命中数/参考意见数；F1 为调和平均。分母为零记为 0，并保留原始数量。
- PLAUSIBLE 单独保留，未匹配不能直接认定误报；FABRICATED 是裁判判断，不是已执行验证的事实。
- 不调用嵌入模型或词面匹配，不计算上游语义对齐、算法冗余惩罚和官方总分。
- 缺少完整答卷、裁判错误、ID 缺失/矛盾或降级时不输出完整分数。保留原始裁判记录，重试另建批次。
- 同套工具/模型对照固定裁判版本、提示词、采样参数及轮次。与 AACR 分别评分，AACR 原有位置筛选规则不变。
- 历史 `swe_prbench` 源码及旧批次保持不变。

当前复用的历史数据/裁判模块仍有 numpy 等 Python 依赖，但不需要 sentence-transformers、PyTorch 或模型权重。
