# COS 未引用执行对象清理

入口：工具箱 → COS 空间整理 → 未引用文件清理。

先将全部 Web、Worker 更新至包含维护屏障的同一版本。禁止混合旧实例执行清理，也不要在维护期间用独立脚本向当前 scope 发布对象。当前仅支持共享 MySQL 集群的 run-data/cluster/<scope>/ 内容寻址对象；其他路径保持只读，不会删除数据库批次或历史记录。

1. 刷新维护状态，点击进入维护。新的修改请求和 Worker 领取暂停，已运行任务继续完成。
2. 等待在途操作和运行任务归零，刷新状态，点击识别未引用对象。扫描会读取数据库引用和已引用对象内容，规模较大时耗时较长；失败不会生成新预览。
3. 核对候选路径、数量和预计释放字节。每次最多 1000 个，最近 24 小时对象受保护。预览 15 分钟有效。
4. 点击确认清理并在对话框中再次确认。服务端重新扫描引用、核对对象 ETag，并使用条件删除。存储接口不支持条件删除或权限不足时停止，不降级为无条件删除。
5. 查看已删除数量和剩余数量，必要时重新扫描。最后主动退出维护，恢复调度及上传。

候选以任务 payload/checkpoint/result、历史尝试、批次、共享 Web 状态中的内容摘要为根，遍历已引用对象中的摘要，保守保留可能的引用。过期上传记录仍有引用时也保留，因此预计释放量可能小于实际可回收量。无法读取引用对象或摘要校验失败时终止。桶版本控制曾开启（含 Suspended）时禁止清理，不把新增删除标记当作释放容量。

维护状态、在途票据、预览和审计保存在现有 bench_web_state 表，不新增表。预览在删除前消耗，重复请求不会重放；部分失败须重新扫描。进程异常可能遗留 cos-writer-* 或 cos-operation，系统不会按超时自行移除：先确认相关进程及子进程全部终止，再由管理员检查并恢复这些状态，避免失联实例仍写入。

预计空间按当前对象大小计算，不是 COS 计费容量；实际释放以控制台为准。未验证真实内网 COS 的 List/GetBucketVersioning/GetObject/条件 DeleteObject 权限及兼容性。无需将密钥填入页面。
