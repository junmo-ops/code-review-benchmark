# LCR 重试演练

在项目根目录执行。Mac / Linux：

```bash
.venv/bin/python tools/rehearse_lcr_retry.py
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe .\tools\rehearse_lcr_retry.py
```

全部场景预计约 1 分钟，单个常见场景约 5 秒。无需启动工作台、准备案例仓库或填写模型配置。

只演练某个场景，例如部分文件失败后续跑：

```bash
.venv/bin/python tools/rehearse_lcr_retry.py --scenario partial-session
```

| 场景参数 | 模拟过程 | 预期行为 |
| --- | --- | --- |
| gateway | 首次返回 504，下次成功 | 重新运行，完成 |
| timeout | 首次子进程一直等待，下次成功 | 1 秒后终止首次进程，重新运行，完成 |
| empty-session | 报错并返回会话 ID，所有文件失败 | 不使用 resume，重新运行，完成 |
| partial-session | 一个文件完成，一个失败 | 使用 resume 复用完成文件，完成 |
| resume-rejected | 部分完成，续跑时被拒绝 | 清除会话 ID，第三次重新运行，完成 |
| exhausted | 每次都返回 504 | 总共运行 3 次，停止并保留失败记录 |
| unauthorized | 返回 401 | 不重试，保留失败记录 |
| recovered-error | 会话先有报错，再有同一文件的完成记录 | 接受已恢复结果，不重试 |
| invalid-json | 首次输出残缺 JSON，下次成功 | 重新运行，完成 |

终端显示每个场景是否符合预期，日志默认保存到项目的 `retry-rehearsals/` 独立目录。`summary.json` 包含实际尝试次数、是否使用 resume、最终成功状态；各场景的 `.log` 包含完整演练过程；场景子目录保留实际子进程执行记录及归档日志。

工具运行真实的 `review_case`、`run_lcr`、进程超时与清理、会话证据读取、结果转换和重试代码。只在演练子进程内替换 LCR 启动命令、仓库路径、进程时限与会话日志目录，程序退出即结束替换。

模拟会话和结果带演练标记，保存在正式 `runs/` 之外，不用于模型评分。演练证明的是工作台侧重试机制；真实 LCR 的文件复用和模型服务稳定性仍需真实调用确认。
