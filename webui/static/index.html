GETTING STARTED

从这里开始.

日常操作不再需要记命令。

01

新建测评批次

选择案例集、已有模型配置和裁判。可直接创建并开始；“仅保存配置”不会调用模型。模型名称会显示在页面，密钥始终留在本机。

02

运行并查看进度

打开批次，点击随状态提示的主按钮。各案例顺序执行，一步失败就停止。可查看实时日志、停止任务，已完成答卷不会丢失。

03

阅读报告，保留证据

在“报告”中阅读中文报告；“文件”里查看原始输出和评分证据。生成归档后可下载完整结果，不需要寻找目录。

导入案例集

打开左侧“案例集管理”，选择案例 ZIP 并点击“上传并导入案例集”。可重复导入其他案例集，完成后在新建测评或多模型实验中选择使用。

单模型与多模型怎么选

单模型测评：运行一个模型，也可分步检视和评分。多模型实验：在统一条件下顺序运行多个模型，单案例失败后继续；结果对比：读取已有结果，不调用模型。两类入口的时限不同，请在提交前核对执行条件。

恢复与对比

检视中断：先查看案例日志。若进程成功但答卷未转换，可选中该案例点击“恢复答卷”；确需重试时勾选“允许重跑所选未完成案例（可能产生费用）”。默认不会自动重试。

模型、裁判或超时参数改变时新建批次。MCR 是多轮专项，直接模型成绩与 LCR 成绩分开；缺少状态字段不会当成问题已解决。

c-CRAB 执行验证专项

选择 c-CRAB 和 DeepSeek 配置创建批次，再点击“检查准备”和“运行单例验证”。它先做容器测试对照，再检视、修复和执行发布测试；无意见则跳过修复，结果不使用 F1。当前支持固定的 1 个 NetworkX 案例，每批次仅执行一次。

运行边界

本页面只监听本机。关闭浏览器不会终止服务中的任务；关闭服务终端或关机则会中断。它不是云端后台服务，也不会绕过公司平台的任务时限。

在“模型配置”中新增 DeepSeek / Qwen，密钥写入运行服务器的配置文件，不回显。Linux Cloud 的部署与长任务能力需要在目标平台单独验证。
