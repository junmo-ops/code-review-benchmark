# 两套案例集各跑一例

在 `code-review-benchmark` 根目录执行。使用 `model.local.json` 中现有 DeepSeek 配置；下面每条命令都是同步前台任务，模拟 Cloud 的独立命令执行。

扩展工具或模型对照前，先按[测评对比规则](测评对比规则.md)固定实验条件。当前两套单例用于接入验证；新批次均默认使用 Martian Offline 大模型裁判，无需嵌入模型。选择原始评分时在 init 增加 `--evaluator original`。详见[裁判对比](裁判对比.md)。

## AACR（主测）

```bash
run="aacr-one-$(date +%Y%m%d-%H%M%S)"
.venv/bin/python local.py --timeout-seconds 60 init --suite aacr --run-id "$run" --dataset data/pilot1.jsonl --timeout-minutes 10
.venv/bin/python local.py --timeout-seconds 60 check --run-id "$run"
.venv/bin/python local.py --timeout-seconds 60 preview --run-id "$run" --instance 'cline__cline@419534c'
.venv/bin/python local.py --timeout-seconds 800 review --run-id "$run" --instance 'cline__cline@419534c'
.venv/bin/python local.py --timeout-seconds 1800 eval --run-id "$run"
.venv/bin/python local.py --timeout-seconds 60 export --run-id "$run"
```

## SWE-PRBench（补充验证）

```bash
run="swe-prbench-one-$(date +%Y%m%d-%H%M%S)"
.venv/bin/python local.py --timeout-seconds 60 init --suite swe_prbench_llm --run-id "$run" --dataset data/swe-prbench-pilot1.jsonl --timeout-minutes 10
.venv/bin/python local.py --timeout-seconds 60 check --run-id "$run"
.venv/bin/python local.py --timeout-seconds 60 preview --run-id "$run" --instance 'stylelint__9060'
.venv/bin/python local.py --timeout-seconds 1400 review --run-id "$run" --instance 'stylelint__9060'
.venv/bin/python local.py --timeout-seconds 600 eval --run-id "$run"
.venv/bin/python local.py --timeout-seconds 60 export --run-id "$run"
```

`review` 的时限是最大等待上限，提前完成即返回。失败先看 `raw/`、`diagnostics/`，不要重跑整批。已有完整答卷会跳过；评分失败仍保留检视答卷，无需重新调用 LCR。SWE 评分成功后再次 `eval` 拒绝覆盖，重建报告使用 `report`。

每轮结果在 `runs/<run-id>/`，包含数据/版本冻结、原始检视、标准答卷、裁判请求与响应、指标和 `report.zh-CN.md`；`export` 导出同名 `-results.tar.gz`。

SWE 这例按官方 eval_100 中 diff 字符长度最小选出，先定样本后检视，不按成绩筛选。保留完整官方数据记录、人工标注与 A/B/C 冻结上下文，来源 revision 和逐文件哈希在 `data/sources/swe_prbench/provenance.json`。

**SWE 原始纯大模型协议（`--evaluator original`）用于内部对照，不复现官方榜单**：使用完整仓库、DeepSeek 裁判，仅按裁判确认结果做一对一计数，无嵌入和词面补判。新批次选择 `swe_prbench_llm`；旧 `swe_prbench` 保留历史评分。AACR 和 SWE 继续分别报告，不能直接混算。

## 迁移到行内 Cloud

源码包与资源包同步更新后，先离线安装默认 AACR 环境，再恢复 SWE 仓库：

```bash
python3 tools/setup.py
.venv/bin/python tools/setup.py --repos-only --suite swe_prbench --dataset data/swe-prbench-pilot1.jsonl
```

在平台安全环境变量中设置 LCR/JUDGE 接口与令牌。Cloud 用 `.venv/bin/python cloud.py` 代替 `local.py`；`review` 增加 `--external-timeout-seconds 1400`，平台命令 timeout 设置至少同样时长，并保留少量落盘余量。必须先在平台验证单例，Mac 试跑不能证明 Cloud 断线存活、持久化或长任务限额。

## 后续导入更多 SWE 案例

下载同一个官方数据 revision 的 `dataset` 目录（含 `prs.jsonl`、`annotations/`、`contexts/`），离线执行：

```bash
.venv/bin/python tools/import_swe_prbench.py --source /path/to/dataset --task-id stylelint__9060 --output data/swe-custom.jsonl
```

多个案例可重复 `--task-id`。再准备对应仓库和 Git bundle，并记录数据 revision、选择规则和哈希。本次 stylelint 使用 `bundles/stylelint__stylelint.git.tar.gz`（含 shallow 边界的 Git 元数据快照），安装脚本支持直接离线恢复；不能将浅仓库简单打成 bundle，否则恢复时可能缺少父提交。未知来源清单会标记为 `unverified_custom_dataset`，不会自动认定为正式基准。


## 本次真实试跑结果（2026-09-30）

检视及裁判均为 `deepseek-flash`，使用真实 API，无 Mock。

| 案例集 | 批次 | 案例 | 检视耗时 | 评分结果 |
|---|---|---|---|---|
| AACR | aacr-smoke-20260930-230330 | cline__cline@419534c | 32 秒 | 2 条意见，命中 2 条参考中的 1 条；三轮平均 P/R/F1 均 0.5 |
| SWE-PRBench 适配实验 | swe-prbench-smoke-20260930-231600 | stylelint__9060 | 8 分 49 秒 | 1 条意见被裁判判为 PLAUSIBLE，未匹配 1 条人工参考；P/R/F1 均 0 |

SWE 的未匹配意见被判为“合理但参考答案未提及”，不是“已经证实为误报”。原始分类与归一化匹配均已保存。两套评分协议不同，表格用于确认各自流程执行结果，不用于互相比高低。

两轮均已生成 `report.zh-CN.md` 与结果 tar.gz。LCR 二进制/规则与批次冻结哈希一致；未调整 CLI 行为。SWE 检视累计 Token 2,281,087，其中缓存读取 2,047,232；这些是各次请求累计统计，不是单个上下文长度或实际计费金额。


## 已有答卷切换为纯大模型评分

只重新评分，不重跑检视。创建新批次时保持原检视模型、接口和数据不变：

```bash
run="swe-llm-$(date +%Y%m%d-%H%M%S)"
.venv/bin/python local.py --timeout-seconds 60 init --suite swe_prbench_llm --evaluator original --run-id "$run" --dataset data/swe-prbench-pilot1.jsonl --timeout-minutes 10
.venv/bin/python tools/reuse_answers.py --source-run runs/swe-prbench-smoke-20260930-231600 --target-run "runs/$run"
.venv/bin/python local.py --timeout-seconds 600 eval --run-id "$run"
.venv/bin/python local.py --timeout-seconds 60 export --run-id "$run"
```

复用工具验证数据/答卷范围和检视配置，记录来源及哈希，拒绝覆盖已有结果。新分数保存在 `metrics/swe_prbench_llm.json`，报告标注内部协议；旧批次保持原样。

已验证的新批次：`swe-llm-20261001-02`，复用完整答卷，只重新评分。首次裁判因 4000 Token 截断被拒绝计分，保留在 `swe-llm-20261001-01`；当前统一冻结上限为 8192。
