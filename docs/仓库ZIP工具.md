# 仓库 ZIP 工具

从侧栏“工具箱”进入，打开“仓库 ZIP 工具”，选择文件并点击“上传并处理”，完成后下载 ZIP。
每个包须包含一个带完整 .git 的项目目录；输出按项目目录名命名，最多两个本地分支，原提交 SHA 保持不变。

单包最大 2 GiB，一次最多选择 5 个，后台串行处理。主分支默认根据 origin/HEAD 识别，缺失时可在上传前填写主分支。
刷新后仍可查看后台任务。上传未结束时，重新选择同一文件续传；尚未上传的批量文件需重新选择。

结果和记录存放在数据目录 zip-tool，不登记案例集或仓库，不调用模型、不推送 Git。任务成功或失败后保留 24 小时，访问工具或启动处理时清理过期文件；也可手动清理。容器重建且无持久化磁盘时文件会丢失，请及时下载。
默认解压上限 8 GiB，可通过 BENCH_ZIP_UNPACK_MAX_MIB 调整。大量文件会占用临时磁盘，工具按包检查可用空间。

处理结果附推送说明和校验清单。远端已有的旧分支不会自动删除；推送后应在全新克隆上核验清单。

命令行使用同一模块：

```sh
python -m repository_migration.history --zip-dir /path/to/zips --output /path/to/output
```
