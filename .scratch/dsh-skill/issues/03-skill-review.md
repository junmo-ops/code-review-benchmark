# 03: 指定 Skill 版本完成常规测评

**What to build:** 测评人员在现有被测工具选项下选择一个已导入 Skill 版本，使用 Linux DSH 实际加载该版本并完成检视、独立评分与报告。批次始终可追溯到完整待测内容，不修改 Skill 策略，也不把未加载或受限执行当成 Skill 成绩。

**Blocked by:** 01: 无待测 Skill 基线贯通现有测评；02: 完整 Skill 包导入与不可变版本管理。

**Status:** ready-for-agent

- [ ] 现有创建表单支持选择一个成功导入的 Skill 版本，或明确选择无待测 Skill 基线；模式互斥，切换工具或模式时不会携带无效参数，不自动创建其他组或批次。
- [ ] 版本和模式经创建请求、队列、初始化、执行及报告完整传递并冻结；后端校验版本可用性、完整内容和请求一致性，不以名称或前端检查替代。
- [ ] 排队和执行时使用绑定的不可变内容，后续同名 Skill 导入不能改变旧批次；冻结条件改变或内容损坏时阻断，不静默改用其他版本。
- [ ] Linux DSH 实际显式加载指定 Skill 及可读取的配套资源，保持原文和检视策略；加载模式与基线采用一致任务、答卷契约、只读权限及新会话隔离。
- [ ] 保存并核验实际加载证据，覆盖显式注入和工具加载的不同记录形式；不能仅凭启动参数、发出加载指令或被截断的事件投影宣称加载成功，也不要求显式注入必须产生 Skill 工具调用。
- [ ] 缺少加载证据、未完整结束、格式错误和非法意见不能进入完整答卷；不借助另一个模型改写结论或修复格式后评分，完整零意见答卷仍有效。
- [ ] 依赖禁用能力的 Skill 明确标为不支持并保留依据，不静默削弱后发布质量分；包中存在但未使用的脚本不被武断认定为必需能力。
- [ ] 输出沿用现有答卷位置和内容契约；相同 Skill 答卷可分别使用现有原始 AACR 或 Martian 协议，评分选择和裁判行为不与 reviewer 耦合。
- [ ] 普通报告、执行记录和下载包含 Skill 版本或基线模式、完整性、加载证据、脱敏原始结果及已知用量；不新增独立实验、跨批次排名或自动基线差值。
- [ ] 通过现有公开 API、队列和浏览器路径验证一次 Skill 测评，并用 Linux DSH 与本地接口替身验证实际加载和重试行为；覆盖无效版本、排队后新增版本、基线切换和不支持的能力。
- [ ] 按项目约定完成 check、verify、专项测试及本地 e2e，回归 LCR、服务端 Agent、Cline 和既有多模型流程；自动回归不访问真实模型或真实 COS。
