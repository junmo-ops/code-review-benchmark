# 02: 完整 Skill 包导入与不可变版本管理

**What to build:** Skill 作者和测评人员在工作台现有资源管理范围中导入完整待测 Skill 包，查看可用版本、资源和内容身份，并保留可追溯的原包。该本地资源管理路径可独立演示，不以 DSH 运行环境准备完成为前提，也不提前声称已能执行 Skill 检视。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 本地模式提供完整的上传、导入进度、成功或失败反馈、版本列表及版本详情；一个包对应一个 Skill 及其引用资源，不只提取主说明，也不引用可变的服务端目录。
- [ ] 完成导入前验证 Skill 元数据和包结构，保留原 ZIP、逐文件清单及完整内容身份；压缩包字节摘要与解包内容身份分开记录。
- [ ] 内容变化形成新的不可变版本，已有版本的内容不被同名导入覆盖；展示名称不充当版本身份，重复导入不能损坏已有可用内容。
- [ ] 解包拒绝路径穿越、绝对路径、符号链接、重复或冲突条目及不支持的文件类型，限制文件数量和解压大小；采用结构化 ZIP 元数据及现有安全导入模式，不执行包内内容。
- [ ] 主说明及引用资源的内容保持原样；包中存在脚本不直接等于该 Skill 必须执行脚本，导入不擅自改写检视策略或替换资源。
- [ ] 不完整、失败或内容不一致的版本不作为可用版本发布；通过后端验证资产和引用，不仅依赖前端表单校验。
- [ ] 本票只完成本地资产流程；在 COS 模式尚未接入时明确拒绝或提示当前不支持，不把仅本地落盘显示成已持久化成功，后续由 05 补齐。
- [ ] 用临时目录、合法资源包和危险包通过现有资源 API 及浏览器入口验证导入、失败反馈、不可变版本和原包追溯；不依赖 DSH、真实模型或真实 COS。
- [ ] 按项目约定完成 check、verify、本票专项及上传页面 e2e；导入异常恢复排查运行 e2e:explore 并记录注入方式、持续时间及模拟边界，未通过时保留阻塞而非标为 done。
